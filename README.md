# Henrique Portfolio

Portfólio profissional de Henrique Barucco, desenvolvido com Next.js e TypeScript.

## Desenvolvimento

```bash
pnpm install
pnpm start:dev
```

## Validação

```bash
pnpm test
pnpm lint
pnpm build
```

Os testes usam o runner nativo do Node.js com remoção experimental de tipos para validar os dados editoriais do portfólio.
